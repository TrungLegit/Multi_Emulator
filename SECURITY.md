# Security Policy

## Supported Versions

Currently, the latest `main` branch of **Multi_Emulator** is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of **Multi_Emulator** seriously. If you discover a security vulnerability, please report it responsibly:

1. **Do not** open a public GitHub issue for security vulnerabilities.
2. Use [GitHub Private Vulnerability Reporting](https://github.com/TrungLegit/Multi_Emulator/security/advisories/new) if enabled on the repository, or contact the maintainer directly via [@TrungLegit](https://github.com/TrungLegit).
3. Include detailed steps to reproduce the issue, potential impact, and any suggested remediation.

We will acknowledge receipt of your report as quickly as possible and work with you to understand and resolve the issue before any public disclosure.
